# Страница ошибки «Волчий след» (вариант Г)

Отложено 18.10.2026: на сайт пошёл вариант А «Нет фокуса», а этот владелец хочет
когда-нибудь поставить.

Что это: следы лапок уходят за край, «4**0**4» с выделенным нулём, заголовок
«Волчица унесла эту страницу» (для 500 — «Волчица споткнулась»). Перекликается
с подвалом «Волчий след» и колосом Хоро.

## Посмотреть

Тестовый сайт (`prototypes\.venv\Scripts\python prototypes\_server\fake_site.py`), затем
http://127.0.0.1:5090/_proto/безумные-идеи/error-wolf/err?v=d&code=404 (или `code=500`).
В `err.html` лежат все четыре варианта, нужен блок `v == 'd'` и стили «Г — Волчий след».

## Как вернуть

Страницы ошибок на сайте: `scr/templates/error.html` (404 и 500 с шапкой и подвалом),
`scr/templates/error_static.html` (запасная 500 без БД), стили — `scr/static/css/error.css`.
Заменить в `error.html` блок рамки автофокуса (`.af`) на разметку следов `.trail` + `.num`
и перенести стили `.vD …` в `error.css`; тексты взять из этого файла.
Лапки — SVG из пяти эллипсов; анимация только прозрачностью (`pawIn`), без `filter`.
