# Прототипы блока «Признание & Опыт» (страница «Обо мне»)

Шесть вариантов, показанных владельцу 2026-10-06. На сайт перенесён вариант **В — Стопка**.
Вариант **Е — Развороты** (аккордеон: строка «год — название», по нажатию раскрывается
диплом, описание и ссылка) владелец просил не забыть: возможно, заменит им «Стопку».

- `awards.js` — строит все варианты (`window.AW_V`: a — сушилка, b — хронология, c — стопка,
  d — контактный лист, e — выставка, f — развороты). Код варианта Е — секция «Е: РАЗВОРОТЫ».
- `awards.css` — стили всех вариантов, у Е — секция «Е: РАЗВОРОТЫ».
- `awards_cmp.html` — страница сравнения. Работала через тестовый сервер с подменённой базой
  (`/_proto/awards_cmp`, `?v=a…` подключал `about_a<x>.css/js`), сама по себе не откроется.

Папка не заливается на хостинг (см. `.vscode/sftp.json`).
